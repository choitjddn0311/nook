# Nook 로드맵과 진행 상황

> 다음 작업을 정할 때 읽는다. 각 단계는 브랜치 → PR → 검증 → 병합 순서로 진행하고, 단계 안의 세부 계획은 시작할 때 다시 정한다.

### 1차: MVP (최소 기능)
| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 프로젝트 뼈대 (Next.js, TypeScript, Tailwind) | 완료 |
| 2 | 디자인 기반 (토큰, 폰트, 낮/밤 테마) → 모노크롬으로 재설정 | 완료 |
| 3 | DB: `posts` 테이블 + RLS | 완료 |

### 2차 이후: 핵심 기능 확장
MVP가 끝난 뒤 아래 순서로 진행한다. 이미 MVP에서 만든 부분은 "(MVP)"로 표시했다.

**11. 자유 기록 강화 (Free Writing)** — 완료
- 제목 없이 본문만 작성 / 제목은 선택 (MVP)
- 자동 저장, 작성 중 저장 상태 표시 ("저장 중…", "저장됨")
- 글자 수·단어 수 표시
- 참고: 자동 저장은 PWA 오프라인 작성과 함께 설계한다 (임시 저장 → 연결되면 DB 저장).

**12. Markdown 작성 지원** — 완료 (글마다 일반/Markdown 선택, 새 글은 마지막 방식 기억, PC 나란히 미리보기·폰 전환)
- 본문을 Markdown으로 쓰고, 보기 화면에서 서식으로 보여 준다.
- 참고: 렌더링 라이브러리가 필요하다 → 추가 전에 크기·보안(XSS)을 검토하고 사용자 확인을 받는다.

**13. 생각 보관함 강화 (Thought Archive)** — 완료 (검색: 홈 '새 글 쓰기' 위 떠 있는 찾기 버튼 → 왼쪽으로 늘어나는 짧은 검색칸, 제목·본문 검색. 날짜순 정렬은 넣었다가 사용자 결정으로 뺌 = 항상 최신순)
- 제목이 없으면 본문 첫 문장으로 미리보기 (MVP: 첫 줄)
- 기록 상세 보기·수정·삭제 (MVP), 태그 (MVP 8단계)
- 키워드 검색 (제목·본문), 날짜순 정렬 (최신순 / 오래된 순)
- 즐겨찾기 → DB 변경 필요 (`posts`에 즐겨찾기 칸 추가)
- 카드 형태 표시 → **결정됨: 지금의 구분선 목록 유지** (디자인 원칙 "카드 나열 피하기"와 맞춤)
- 즐겨찾기 모아 보기 → **결정됨: 홈 태그 줄 맨 앞 '★ 즐겨찾기' 칩으로 거르기** (별도 화면 없음)

**14. 과거의 생각 (On This Day)** — 완료
- 과거 같은 날짜(월·일)에 쓴 기록 보기
- 1년 전, 6개월 전, 한 달 전 기록 탐색
- 과거 기록에 새로운 생각 덧붙이기 → `post_notes` 표 (원래 글은 그대로, 아래에 날짜별 메모)
- 들어가는 곳: 홈 맨 위 한 줄 안내(해당하는 날만) + `/past` 화면 + 헤더 '지난 생각' 링크

**15. 랜덤 생각 (Random Thought)** — 완료 (들어가는 곳: 홈 하단 바 '아무 글 보기')
- 기존 기록 중 하나를 무작위로 보여 주기, "다른 기록" 버튼으로 바꾸기
- 다시 읽고 새로운 생각 덧붙이기 (14단계의 덧붙이기 기능 재사용)

**16. 생각 통계 (My Thinking)** — 완료 (마이페이지 `/me`에 계정 정보와 함께. 헤더 '로그아웃' 자리 → '나' 링크, 로그아웃은 마이페이지 맨 아래)
- 전체 기록 수, 기록한 날짜 수, 연속 기록 일수
- 월별 기록량, 자주 쓴 태그
- 기록 활동 달력 (잔디 형태) 및 통계 화면
- 참고: 날짜 계산은 한국 시간 기준 (`src/lib/format.ts`와 같은 방식). 차트는 모노크롬 톤을 유지한다.

### 1.0.0 — 2026-11-06

- 확인 안 된 것: 안드로이드 실기기 설치·동작 (iOS·PC 브라우저만 확인)
- 이후 작업은 새 버전 번호(1.x)로 이어 간다.
