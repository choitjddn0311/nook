# Nook 디자인·접근성 세부

> 화면을 만들거나 고칠 때 읽는다. 핵심 원칙은 CLAUDE.md에 있다.

## 디자인 방향: 모노크롬
- 흑·백·회색만 쓴다. 회색은 **순수 중립**(노란빛·푸른빛 없음).
  순수한 흰색(#FFF)과 검정(#000)은 눈부심과 번짐 때문에 쓰지 않고, 중립 회색의 끝단을 쓴다.
- **포인트 색이 없다.** 강조는 색이 아니라 진하기(본문색 vs 보조색), 굵기, 밑줄로 한다.
  주요 버튼은 본문색 배경 + 배경색 글자(반전)로 만든다.
- 그라데이션, 텍스처, 장식용 그림자를 쓰지 않는다. 면은 `--bg`와 `--surface`의 밝기 차이로만 나눈다.
- 기본은 **라이트 테마(낮)**다. 밤에 쓰기 좋은 **다크 테마(밤)**를 함께 제공한다.
  - 처음에는 기기의 시스템 설정(`prefers-color-scheme`)을 따른다.
  - 사용자가 직접 낮/밤을 전환할 수 있고, 선택한 값을 기억한다.
- 글 쓰는 화면은 방해 요소를 최소화한다.
- 폰트: **Pretendard 하나**(본문·UI 공통). 위계는 글꼴을 바꾸지 않고 크기·굵기·행간으로 만든다.
  큰 글자는 자간을 좁히고(-0.02em), 본문은 0에 가깝게, 행간은 본문 넉넉히·제목 좁게.
- 애니메이션은 짧고 부드럽게 한다. 누르는 순간 바로 반응한다. `prefers-reduced-motion`을 존중한다.
- 피할 것: 색으로 강조하기, 그라데이션, 네온·채도 있는 색, 과한 그림자, 대시보드 같은 딱딱한 카드 나열.

### 색상 토큰 (대비 검증 완료, 조정 가능)
| 토큰 | 낮 (기본) | 밤 | 용도 |
|---|---|---|---|
| `--bg` | #FAFAFA | #141414 | 배경 |
| `--surface` | #F0F0F0 | #1F1F1F | 입력창, 글쓰기 영역 (배경보다 살짝 눌린 면) |
| `--text` | #171717 | #EDEDED | 본문 |
| `--text-muted` | #666666 | #A1A1A1 | 날짜, 태그 등 보조 텍스트 |
| `--accent` | #171717 | #EDEDED | 주요 버튼 배경, 포커스 링 (= 본문색) |
| `--accent-contrast` | #FAFAFA | #141414 | 주요 버튼 글자 |
| `--border` | #E5E5E5 | #2E2E2E | 장식용 구분선 |
| `--scrim` | #171717 60% | #171717 60% | 사용법 안내에서 화면을 어둡게 덮는 막 (글자가 올라가지 않음) |

대비 (낮 / 밤): 본문-배경 17.2 / 15.7, 본문-surface 15.7 / 14.1, 보조-배경 5.5 / 7.1,
보조-surface 5.0 / 6.4, 버튼 글자 17.2 / 15.7. 모두 WCAG AA 통과.
`--border`는 장식용이라 대비가 낮다. 입력창처럼 경계가 꼭 보여야 하는 요소는 border만으로 구분하지 말고,
`--surface` 배경 차이와 `--accent` 포커스 링으로 구분한다.

**색의 유일한 예외: 소셜 로그인 버튼.** Google 버튼 디자인 안내를 따라 회색 버튼에 로고만 원래 색으로 둔다. 다른 곳에는 색을 쓰지 않는다.

색상은 반드시 CSS 변수(토큰)로 정의하고, 컴포넌트에 색상 값을 직접 쓰지 않는다.
토큰을 바꾸거나 새로 추가하면 대비를 다시 계산해서 이 표에 기록한다. 토큰 정의는 `src/app/globals.css`.

## 접근성 기준
- 텍스트 대비 WCAG AA 이상 (본문 4.5:1, 큰 글씨 3:1). 낮/밤 두 테마 모두 확인한다.
- 모든 기능은 키보드만으로 사용할 수 있어야 하고, 포커스 표시가 보여야 한다.
  - 버튼·링크는 본문색 테두리(outline)로 포커스를 보여 준다.
  - 글 쓰는 칸(제목·본문·태그)은 장식 없이 깜빡이는 커서로 포커스를 보여 준다(깨끗한 종이 느낌). 글 중간에 놓인 덧붙이기 칸은 보조 글자색 1px 밑줄(대비 5.5:1 이상, WCAG 1.4.11 통과), 쓰는 중엔 본문색 2px.
  - 로그인 입력칸은 surface 상자 그대로 둔다(1.0.0 결정). 배경과 대비 1.1:1로 1.4.11 미달인 알려진 항목이며, 라벨과 포커스 링으로 구분한다.
- 터치 영역은 최소 44×44px로 한다. 주요 버튼은 폰에서 엄지가 닿는 하단에 둔다.
- 네이티브 HTML 요소를 우선 사용한다. 커스텀 컴포넌트는 적절한 ARIA를 갖춘다.
- 모바일 우선으로 설계한다. 기준 화면: 375px(폰), 768px(태블릿), 1280px(PC).
- PWA로 만들어 홈 화면에 설치하고 오프라인에서도 쓸 수 있게 한다.
